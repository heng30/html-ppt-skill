📖 简介

🛰️ 纯Rust的GNSS与航天动力学引擎

sidereon 可传播卫星轨道、预测过境、求解精确位置（SPP/RTK/PPP），并在坐标框架与时间尺度之间转换——对标领域权威（Vallado、Skyfield、IGS、IERS）。

🦀 纯Rust#![forbid(unsafe_code)]，安全至上
⚡ 高性能原生速度，无FFI开销
📦 单cratecargo add sidereon 即获全栈
✅ 严格验证对标Vallado、Skyfield、IGS
🔍 设计理念：底层 sidereon-core 提供完整引擎，表面层 sidereon 提供薄而符合人体工学的API——丰富的结果结构体和统一的 Error 枚举。
🚀 快速入门

📡 ISS过境预测

无需数据文件，无需配置：给一个TLE和地面站，即可预测卫星何时出现在地平线以上。

安装 
cargo add sidereon
Rust · 核心代码 
use sidereon::passes::{find_passes_for_satellite, GroundStation, PassFinderOptions, UtcInstant};
use sidereon::sgp4::Satellite;

let iss = Satellite::from_tle(line1, line2).expect("valid TLE");
let station = GroundStation {
    latitude_deg: 37.87, longitude_deg: -122.27, altitude_m: 52.0,
};
let options = PassFinderOptions { elevation_mask_deg: 10.0, ..Default::default() };
let passes = find_passes_for_satellite(&iss, station, start, end, options)
    .expect("valid inputs");

📍 精确定位

⚡ SPP / RTK / PPP 定位解算

输入伪距观测值和SP3精密星历，即可获得最小二乘定位解。

Rust · SPP定位 
use sidereon::positioning::{Corrections, Observation, SolveInputs, SolvePolicy};
use sidereon::{load_sp3, solve_spp, GnssSatelliteId, GnssSystem};

let sp3 = load_sp3(&std::fs::read("igs_product.sp3")?)?;
let inputs = SolveInputs {
    observations: vec![
        Observation { satellite_id: GnssSatelliteId::new(GnssSystem::Gps, 1)?,
                      pseudorange_m: 21_000_123.4 },
        // ...more satellites
    ],
    corrections: Corrections::IONO_TROPO,
    ..spp_inputs
};
let fix = solve_spp(&sp3, &inputs, /* with_geodetic */ true, policy)?;
✅ 统一模式：RTK（浮点/固定）、PPP（浮点/固定）遵循相同模式——类型化配置输入，结果结构体含ECEF/大地坐标、残差、DOP和状态。批量解算 solve_spp_batch 可跨rayon线程池并行，与串行路径位精确一致。
