01 · 简介 sidereon · GNSS

纯 Rust 的 GNSS 与航天动力学引擎

传播卫星轨道、预测过境、求解精确位置（SPP/RTK/PPP），并在坐标框架与时间尺度之间转换。

M1
轨道传播
SGP4/TLE 与数值传播，覆盖过境预测、地面轨迹、大气阻力与再入预测。
M2
定位解算
SPP、RTK（浮点/固定）、PPP（浮点/固定），共用一套输入模型与结果结构体。
M3
坐标与时间
TEME↔GCRS↔ITRS、大地↔ECEF，UTC/TT/TDB/UT1 之间无损转换。
M4
数据与修正
SP3、RINEX、CRINEX、ANTEX、Bias-SINEX，以及 SBAS 与 RTCM SSR 修正。
M5
严格验证
SGP4 位精确对标 Vallado，框架对标 Skyfield 与 IERS，定位对标 IGS 产品。
引擎能力与 API 人体工学分开，表面层保持精简。 core / facade
02 · 快速入门 sidereon · passes

ISS 过境预测

无需数据文件，无需配置：给一个 TLE 和地面站，即可预测卫星何时出现在地平线以上。

Rust · 核心代码 
use sidereon::passes::{find_passes_for_satellite, GroundStation, PassFinderOptions};
use sidereon::sgp4::Satellite;

let iss = Satellite::from_tle(line1, line2).expect("valid TLE");
let station = GroundStation {
    latitude_deg: 37.87, longitude_deg: -122.27, altitude_m: 52.0,
};
let options = PassFinderOptions { elevation_mask_deg: 10.0, ..Default::default() };
let passes = find_passes_for_satellite(&iss, station, start, end, options)
    .expect("valid inputs");
输入只有 TLE、地面站和时间窗，其余用默认配置。 find_passes_for_satellite

04 · 精确定位 sidereon · positioning

SPP / RTK / PPP 定位解算

输入伪距观测值和 SP3 精密星历，即可获得最小二乘定位解。

Rust · SPP 定位 
use sidereon::positioning::{Corrections, Observation, SolveInputs};
use sidereon::{load_sp3, solve_spp, GnssSatelliteId, GnssSystem};

let sp3 = load_sp3(&std::fs::read("igs_product.sp3")?)?;
let inputs = SolveInputs {
    observations: vec![Observation {
        satellite_id: GnssSatelliteId::new(GnssSystem::Gps, 1)?,
        pseudorange_m: 21_000_123.4,
    }],
    corrections: Corrections::IONO_TROPO,
    ..spp_inputs
};
let fix = solve_spp(&sp3, &inputs, /* with_geodetic */ true, policy)?;
统一模式：RTK（浮点/固定）、PPP（浮点/固定）遵循相同模式，类型化配置输入，结果结构体含 ECEF/大地坐标、残差、DOP 和状态。批量解算 solve_spp_batch 可跨 rayon 线程池并行。
换的是配置与策略，不换调用形状。 spp / rtk / ppp
05 · 功能全景 sidereon · modules

一个 crate 覆盖的六块能力

从轨道传播到射频分析，模块边界按物理对象划分，不按算法划分。

01
轨道传播
SGP4/TLE、数值传播、再入预测、过境与地面轨迹。
02
坐标与时间
TEME↔GCRS↔ITRS、大地↔ECEF、UTC/TT/TDB/UT1、EGM96/2008。
03
天体与历书
日月行星视位置、升降时刻、月相日月食、JPL SPK 内核。
04
观测几何
角距与位置角、相位角、视星等、晨昏线。
05
定位解算
SPP、RTK、PPP、DOP、速度、故障检测。
06
GNSS/INS 融合
松/紧耦合、RTS 平滑、中断速度匹配、非完整约束。
六块能力共用同一套时间与坐标框架。 modules / astro
06 · 总结 sidereon · takeaway

核心要点

一个 crate，一套坐标与时间框架，五种语言同一份数值。

纯 Rust 引擎

  • #![forbid(unsafe_code)]
  • 单 crate 重新导出全栈

核心能力

  • SGP4 轨道传播与过境预测
  • SPP/RTK/PPP 精确定位

多语言统一

  • Rust / Python / C / Elixir / WASM
  • 同一引擎，相同数值

严格验证

  • SGP4 位精确对标 Vallado
  • 框架对标 Skyfield / IERS

适用场景

  • 地面站调度与过境预报
  • 高精度定位与组合导航

约束与边界

  • 不做信号层仿真
  • 不绑定特定接收机厂商
核心价值：一个 cargo add sidereon 即可获得完整的 GNSS 与航天动力学工具链，从卫星传播到精确定位，纯 Rust 实现，严格验证。
把整条链路收进一个 crate，是这套 API 唯一的设计目标。 takeaway
